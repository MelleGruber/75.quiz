# 75. Quiz im Bahnhof

Statische GitHub-Pages-Version des Quizabends vom 18. November 2026.

## Veröffentlichung

Die Dateien in diesem Ordner können direkt in ein GitHub-Pages-Repository kopiert werden.

- Einstieg: `index.html`
- Styles: `assets/site.css`
- Quizdaten und Logik: `assets/quiz.js`
- Bilder: `assets/images/`

Die Seite speichert keine Antworten und sendet keine Daten an einen Server. Die Punkteauswertung läuft komplett im Browser. Die Vor-Ort-Auswertung ist separat über den Button „Vor-Ort-Auswertung“ erreichbar.
